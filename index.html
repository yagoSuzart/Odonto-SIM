Como Compartilhar com Sua Amiga
Ela no celular, você no computador — guia passo a passo.
Opção 1 — GitHub Pages (Recomendado, Gratuito)
PASSO 1
Acesse github.com → crie uma conta gratuita (se não tiver)
PASSO 2
Clique em "New Repository" → nomeie como odonto-sim → marque "Public"
PASSO 3
Dentro do repositório: "Add file" → "Upload files" → arraste o arquivo odonto_treinamento.html → renomeie para index.html
PASSO 4
Vá em Settings → Pages → Source: "Deploy from branch" → selecione "main" → Save
PASSO 5
Aguarde ~2 minutos. O link gerado será: seu-usuario.github.io/odonto-sim — mande para ela pelo WhatsApp!
Opção 2 — Netlify Drop (30 segundos, sem conta)
Acesse app.netlify.com/drop
Arraste o arquivo .html para a área indicada
Receba o link instantâneo! Ex: random-name.netlify.app
Opção 3 — Salvar como PDF (para impressão)
Abra o arquivo .html no Chrome ou Edge
Pressione Ctrl+P (Windows) ou Cmd+P (Mac)
Selecione "Salvar como PDF" e marque "Imprimir gráficos de fundo"
